# 按维度打分，换权重而不重问

**输入 → 输出：** 同一批候选的证据和几种偏好方案 → 可解释的多份排序。适用于偏好之间允许取舍的情形，不适合“只要有一个禁项就不能通过”的规则。

每个候选是一个 state；同批就每个独立维度问一道 Score。原例把一份简历分别按 Python 深度、团队领导、系统设计、通才经验打分，再让不同职位使用不同权重，而不是问「这人有多优秀」。每一维都写自己的有序档位，各档描述证据而不写「一般」「较强」。

下面改用文档检索的两个维度说明计算。覆盖度用 5 档（从没涉及到覆盖所有要点），易读性用 3 档（从缺少必要解释到新手可直接读懂）。先按各自的最大下标归一化：

```text
覆盖度 3 / (5−1) = 0.75；易读性 1 / (3−1) = 0.50
专家视图：0.8 × 0.75 + 0.2 × 0.50 = 0.70
新手视图：0.4 × 0.75 + 0.6 × 0.50 = 0.60
```

代码保留逐项分数、量表版本和权重。同一证据、同一问题只改权重时重算排序，不发起推理。把权重交换试一遍，看排序变化能否由各维分数解释。若某维是不得违反的条件，先用独立判断或确定性规则过滤，不能让其他维度的高分抵消。

来源：[TypeSafe · Composite scoring](https://docs.typesafe.ai/patterns/composite-scoring.md)。
