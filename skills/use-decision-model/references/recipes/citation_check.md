# 核查引用：先找原话，再看整节是否支持主张

输入是一份本地原文，以及一条 `{id, claim, quote, section}` 引用；`quote=null` 表示只引章节。输出要分开记录**定位状态**、**主张与章节的关系**、**置信度**和**是否需人工确认**。引文确实存在，不等于作者的结论成立。

1. **建立章节表。** 原例对 RFC 去页眉页脚，按编号标题切段，保留“节号 → 整节原文”。换成手册等格式时改解析器，不用 RFC 的编号规则硬切。
2. **用代码定位。** 把引文和各节中的弯引号换成对应直引号，连续空白压为一个空格并去掉首尾空白。在各节内做精确子串匹配，节号按各级数字排序，取第一个命中节：`found`。读实际命中的整节，而非盲信标注的节号。给了引文但遍历未命中为 `missing`；没有引文则直接读指定节，为 `section-only`。原文未取得或指定节不存在是材料错误，应补材料，不等于找到伪引。
3. **只判语义关系。** 对 `found`、`section-only`，用 `{claim, section: 整节原文}` 问一道 `Choice`：“本节明确说出或直接蕴含主张、明确与主张相反，还是两者都不是？”保存三个选项的分布，取概率最高项。

```text
missing      → fabricated，confidence=null，auto=true（没有模型判断）
supports     → verified
contradicts  → contradicted
says_nothing → unsupported
后三种：auto = (胜出项置信度 >= 0.80)，否则保留暂定判词并送人工确认
```

`auto` 只代表代码能否直接采用**这个判词**；例如 `unsupported` 也可能是自动确定的，但并不允许发布为有出处的事实。缺少关系判定时不能自动通过。

**离线验算。** 假设本地规则第 2 节写“登记邮编是可选步骤。”引用“登记邮编”确有其词，但主张是“不登记邮编就不能提交”。若关系分布为支持 0.01、反驳 0.96、未涉及 0.03，应得 `found / contradicted / auto`。若改问“登记信息将保存十年”，本节没有谈期限；若最高项为“未涉及”且只有 0.56，则是 `unsupported / review`，不是反驳。

**限制。** 精确匹配只认规范化后的连续文字，轻微改写、删节后拼接及跨节引文可能被记为 `fabricated`；该标签描述查找结果，不能据此认定作者有意编造。重复引文也要留意上下文是否选对。源例的 0.80 是复核阈值，应按自己的文档与误判成本校准。
