# 深层分类：每次只比较直接子类

**输入**是一段待分类文本和本地分类树；**输出**是从根到叶的路径，而不只是一个可能重名的标签。树的键用稳定 ID，另存可读描述；同一概念若有多个父节点，按完整路径分别保留。

1. 从根开始，取当前节点的直接子类作 `Choice`（有限单选）的全部候选。把原文和子类描述交给决策模型，问：“哪一个直接子类最符合这段描述？”保留**所有**选项的概率。只有一个子类就直接走过去，不提问，也不计入决策次数。
2. 贪心法每层只走概率最大的边。要保留纠错机会，就用束搜索：同一层对保留的各个非叶节点并行提问，每个子类各延伸一条路径。以真正发生选择的边计算路径分：`exp(sum(log(p)) / 决策次数)`；无决策时为 1，零概率的边得零分。几何平均不会只因路径较长而压低分数。
3. 把新路径与上一轮保留的已完成叶路径合并，按分数取前 `K` 条（原例 `K=3`，不是置信阈值）。直到剩下的全是叶，返回最高分叶路径。设置深度上限时，超限未到叶应标为未完成。

**手算一轮。** 对“吸盘式猫窗床”，假设根下“宠物家具／猫床用品”分别为 `0.52/0.48`。家具下最优的“宠物椅”得 `0.55`，床用品下最优的“窗床”得 `0.92`。贪心第一步已丢掉窗床；保留两路后，窗床路径得 `√(0.48×0.92)≈0.665`，超过宠物椅的 `√(0.52×0.55)≈0.535`。

用上述示意分数即可验证搜索，无需运行模型。记录每个父节点的分布，方便定位哪一层误选或剪枝；有两个非零叶分数时可报告“第一名／第二名”，接近 1 表示难分，不用它剪枝。
