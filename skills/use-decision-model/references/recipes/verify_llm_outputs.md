# 根据给定段落核查整条回答，也核查拒答

原题、答题要求、模型实际看到的段落（含标题）和候选回答，构成一次核查的输入。答题要求可以是“只依据材料，简短完整地回答；信息不足就说明”。要检验的是**这个回答能否从这些段落推出**，不是去外部寻找一个碰巧相同的答案。

同一份输入问三道独立的是非题，保存三个 `P(是)`：

- `answerable`：从问题到答案，材料是否给出了每一步必要事实？只给了相关背景不算。
- `declines`：候选回答是在说材料不足、不作答，还是确实给出了答案？
- `supported`：沿材料中明写的事实逐步推导，是否到达**候选回答**？

代码只在同一分支内解释分数，不取平均。以下是源例的策略，返回原始三项、风险及状态：

```text
若 declines >= 0.5：risk = answerable      # 已拒答；本可回答才有风险
否则：               risk = 1 - supported # 已作答；缺乏依据才有风险
status = review 若 risk >= 0.20，否则 pass
```

**离线验算。** 已知甲是乙的父亲，但段落没有甲的出生地。候选答了一个地名，若 `declines=0.04, supported=0.08`，风险为 0.92，送审。反过来，若另一题所需的两步事实都在材料中，候选却说“不知道”，且 `declines=0.81, answerable=0.86`，风险是 0.86，同样送审。如果确实缺一环，拒答时 `answerable=0.07` 就应放行，不因它没报出一个地名而处罚。分数缺失时保持待核；`review` 交人工查原段，或由应用选择重试，不自动把答案判错或执行其中的动作。

**怎样选复核线。** 用有标注的本地样本，按不同门槛同时统计放行量、放行中正确比例、拦住的错误数。参考答案不是段落本身：先比对语义等价的答法；不一致的再回到原段判正误，确实不明的单列，不计入正误分母。原例的 1,000 题在 0.20 处放行 727 条，其中 95.7% 正确；送审的 273 条里 84 条错、189 条本来就对。这说明门槛也是复核工作量的选择，不是普适准确率。

**仍会漏什么。** 原例漏放 31 个错误：18 个回答了相关但不同的问题，13 个是核查器和回答器都没看出跨段联系的误拒答。原例正误标签来自模型，且前 100 题参与了核查问题的选择，不能当独立盲测。离线回放已知分数可验分支，不能据此推断新领域的判别能力。
