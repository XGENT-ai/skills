# 短名单重排：找出真正支持引文的段落

来源：[TypeSafe 官方配方：Re-ranking](https://docs.typesafe.ai/cookbooks/rerank_typesafe.md)

**输入与结果。** 输入是一段去掉引用标记的文字、带稳定 ID 的本地段落库，以及每个入围段落对应的 Noul 回执。输出仍是同一批段落，只改变顺序；首位是最值得核对的出处，不是已经核实的出处。

1. 按内容去重并保留段落 ID。用 BM25 按词项匹配检索全文库，记录初排顺序，截取前 K 个；原例 K=30。BM25 的任务是让正确段落入围，不要求它能排第一。
2. 对每个入围 ID 单独构造状态 `{query_excerpt, candidate_passage}`。所有段落用同一道 Noul 题：“这段候选文字是否给出了引用处依赖的**具体规则、判断标准或事实**？”明确给出才算正例；仅讨论相同话题不算。离线按查询和候选 ID 取出这道题的 `noul`；各分数不需要合计为 1。
3. 按 `noul` 从高到低稳定排序；同分沿用 BM25 顺序。不要把初排分与 Noul 相加，也不需要先设一个通过门槛。

**手算。** 查询缺失的出处应说明“续借必须在到期前登记”。BM25 的前三段依次是 A（介绍续借服务）、B（规定登记期限）、C（列出可续借书目）。若回执分别为 0.22、0.91、0.22，结果是 **B、A、C**：B 提供规则本身；A、C 同分，次序未变。

**核对。** 有已知出处时，先数它出现在短名单中的查询，再对同一组查询比较重排前后的 Top-1、Top-5 命中数。若正确段落根本没入围，要改初检或扩大 K；重排无法补回它。若已入围却仍落后，核对提问是否把“相关”误写成了“足以支持该说法”。
