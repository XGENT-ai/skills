# 通用开发计划骨架（dev-plan 默认模板）

> 除非用户显式指定其他模板，dev-plan 一律使用本骨架，不依赖目标仓库存在模板文件。
> 按改动面与风险裁剪章节；删除不适用的占位和写作指引，不为满足形式填充内容。
> 目标读者是后续实现者，因此事实、决策、接口、迁移、失败和验收必须闭环。

## 发出前自检

- [ ] 默认使用本文件；未探测或依赖目标仓库中的模板。
- [ ] 计划记录调查日期、commit/version 和 dirty 状态。
- [ ] 顶部实施进度已按真实状态初始化，0/N、M1、里程碑总数和代码基线互相一致；没有预填虚假完成记录。
- [ ] R/NFR/C/A 全部映射；未知数字未被伪造成目标。
- [ ] 关键决策有真实备选、正负后果和重新评估触发；普通选择未被 ADR 化。
- [ ] 复杂设计写清模块、接口、接缝、依赖分类与测试面；没有假想抽象。
- [ ] 契约均为“已核实足够 / 已核实缺口 / 未核实阻塞”之一。
- [ ] 数据约束与生命周期、迁移、兼容和回滚互相一致。
- [ ] 失败模式的检测、恢复和验证在改动面与里程碑中有落点。
- [ ] 验证通过接口观察行为；安全/NFR 条目均可断言或观测。
- [ ] 复用/已核实路径真实存在，新增路径已明确标注。
- [ ] Ready 计划没有影响范围、安全、数据、外部契约或关键 NFR 的未决项。
