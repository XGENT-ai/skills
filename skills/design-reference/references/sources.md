# 按问题选择参考来源

以下是检索入口，不是默认依赖。网站内容、访问方式和收费条件可能变化，执行时核对实际页面；不在 skill 内维护数量、排名或付费 prompt 的副本。

| 当前缺口 | 可用入口 | 取回后应核对 |
| --- | --- | --- |
| 整页设计方向、页面拆解 | [Kage](https://kage.design/)、[Minimal Gallery](https://minimal.gallery/)、[Land-book](https://land-book.com/) | 具体页面及截图；原产品与当前任务是否相似 |
| 字体、颜色、间距和设计语言 | [Refero Styles](https://styles.refero.design/)、[DesignMD](https://designmd.ai/) | 条目来源、实际预览、值的依据；第三方整理不等于产品官方规范 |
| 同类组件的外观、密度与状态呈现 | [Component Gallery](https://component.gallery/) | 跟进设计系统原文；需选择交互模式时衔接 ui-pattern-research |
| 可复用组件与区块 | [shadcn/ui](https://ui.shadcn.com/)、[21st](https://21st.dev/) | 源码、栈兼容、依赖、许可及与现有 token 的映射 |
| 动效目的和实现方式 | [Motion Primitives](https://motion-primitives.com/)、[Kinetics](https://kinetics.colorion.co/) | 真实交互、连续触发、触控、减少动态效果和运行成本 |
| 页面或局部 prompt 的写法 | [VibePrompts](https://vibeprompts.dev/)、[Scrolltide](https://www.scrolltide.co/) | 可访问的正文及预览；把固定风格改成产品适配的选择 |

定价、导航、页脚等局部问题也可沿 Kage 或 Component Gallery 的分类检索。先解决具体问题，不为补齐一套素材库而扩散搜索。

## 可选的机器检索

已连接服务时，可查 [Kage MCP](https://kage.design/mcp-setup) 或 [DesignMD MCP](https://designmd.ai/mcp) 的当前工具与访问条件。Kage 的设计 brief、页面和组件检索可提供素材；DesignMD 提供设计系统检索。执行前检查实际可用工具，不假设 MCP 已安装、匿名可下载或返回内容已经验证。

无 MCP 时使用网页、用户提供的截图或本地素材即可。外部服务只接收检索所需的最少公开信息，不上传内部项目文档来换取参考。

## 参考方法

[Kage 的页面拆解示例](https://kage.design/designs/plane-agents-landing-page)展示了把结构、节奏与品牌内容分开的方法；[Refero 的样式条目](https://styles.refero.design/style/4e3b4717-84c8-4599-baaf-a343c3d619b6)提供按角色组织设计值的例子。这些是方法来源，不是所有项目都要采用的布局或配色。
