# Optimize AGENTS.md

精简所在代码仓库的 AGENTS.md：合并重复、压缩原则表达，并补齐缺失的 Think Before Coding 与 Coding Principles。保留规则含义和项目事实，不以字数牺牲约束。

## 两层内容，不能混写

| 层次 | 放什么 | 写到哪里 |
| --- | --- | --- |
| 优化器规则 | 定位文件、检查 DSL 依赖、读取证据、去重补缺、验证和报告 | 只在本 skill 执行，不写入目标 AGENTS.md |
| 仓库规则 | 原有有效原则、项目专属事实与约束、缺失的编码原则 | 目标 AGENTS.md；原则用精炼的 Prompt DSL 表达 |

[原则素材](assets/coding-principles.md) 是目标文件的候选内容，不是本 skill 的工作流。不得把依赖检查、安装建议、优化步骤、差异报告或评测流程混入目标文件。产物只需保留简短语法释义，不要求后续每次编码重新加载 DSL skill。

## 执行

1. **定位目标。** 用户给定路径优先，否则使用当前工作目录所在仓库的根 AGENTS.md；不把 skill 安装目录当目标仓库。读取目标全文、适用的上层/嵌套规则、override 与引用来源，核对实际宿主的作用域和遮蔽关系；只修改用户指定范围。没有 AGENTS.md 时说明尚无可优化文件，建议先初始化，不自行创建。普通编码、全局规则修改不进入此流程；仅诊断不写文件。
2. **先检查 DSL 依赖。** 从当前可用 skills 定位并读取实际安装的 `use-prompt-dsl/SKILL.md` 及其语言规范，使用 `compose` 形式化规则，不执行素材里的任务。找不到该 skill，说明本仓 skills 未完整安装，停止优化并建议完整安装。可按本仓 README 使用 `npx skills add XGENT-ai/skills` 并选择完整公开技能集；这是给用户的建议，不自动安装，也不写入目标文件。不能跳过读取依赖。
3. **读证据并分类。** 原文逐项区分原则、仓库事实/命令、局部约束、重复与可能过时内容。核对与规则有关的源码、配置及文档，包括相关尾部段落；未读或未证实的内容明确标出。保持现有授权、调用策略、业务约束和局部例外；规则冲突先说明并问清，不以通用原则覆盖项目规则。已获授权的优化直接进行，不额外要求远端评测、任务集或再次批准写入。
4. **瘦身并补缺。** 使用 `use-prompt-dsl` 的 Odyssey `RULE` 片段写原则，只选够用的 `must / must_not / should / prefer`，保留原义务强度、条件、例外和作用域；嵌入 AGENTS.md 时省略 `PROMPT`，不强加 `INTENT / ONTOLOGY / OUTPUT / REVIEW` 或模块包装，不为压缩制造缩写密码或层层引用。合并语义重复，删除有证据的失效内容；命令、路径、专属操作与必要链接保留可直接使用的写法，不凭空补仓库事实。读取[原则素材](assets/coding-principles.md)，按语义检查 Think Before Coding 与八项 Coding Principles：已覆盖的不重复，部分覆盖的只补缺口；按原文语言和结构整合，不必保留编号或另起九段。不得以“信任内部契约”删掉信任边界校验，以“少做”漏掉必要工作，或以里程碑执行跳过必要验收。
5. **回读与核对。** 写回前核对当前文件，保留用户并发修改。仅诊断交付建议；优化请求完成范围内修改后回读 diff：每条旧规则均能对应保留、合并或有据删除，新原则完整且没有重复/冲突；模板条件没有丢失，项目命令、路径和链接有效，优化器流程没有泄漏进目标。已精简且原则齐全时不为产生 diff 重写。只运行与本次文档改动相关的检查及仓库要求的检查，不启动无关测试或行为搜索。

## 交付

简述修改文件、合并/删除与补齐的内容、实际验证及未决冲突。给出前后字符数，区分原内容压缩与原则补齐；总长度因补缺增加时如实说明，不为达到比例删规则。比较瘦身前后时逐项核对语义，不能仅凭变短就声称 agent 行为或任务质量提升。未改文件时说明原因。
