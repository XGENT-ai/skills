# 技能演化与协作

用于已授权维护 skill、prompt 或 agent 流程的任务。普通任务中的一次教训不自动启动持久修改。自进化的产物是经过核对的行为变化与可恢复证据，不以规则条数、实验数或评委赞同数计进展。

利用真实工作积累样本，或评价进化方法本身时，读取 [进化证据](evolution-evidence.md)。区分进化方法、被优化对象和效果环境：真实工作留下样本，进化实践还须记录方法如何使用这些样本及其实际结果。具体业务流程留在项目或评测案例中；只要求采集时不启动对比。

## 选择一个流程所有者

| 当前缺口 | 主流程 | 交给下一环的内容 |
| --- | --- | --- |
| 不知道怎样可靠判断好坏 | [Eval](../playbooks/eval.md) | 固定协议、校准结果、基线、可见性与证据入口 |
| 已有判定，要连续尝试 | [Hillclimb](../playbooks/hillclimb.md)（autoresearch 入口） | 一份搜索日志、候选版本和判定 |
| 有值得比较的结构分叉 | [Arena](../playbooks/arena.md) | 匿名候选、差异、成本和新合成候选；不替代最终确认 |
| 从真实会话提炼重复失败 | [Reflection](../playbooks/reflection.md) | 有出处的机制假设、适用边界与待验证修改 |
| 把确认的教训落实到技能 | [Skill 编写](../playbooks/authoring-a-skill.md) | 最小指令／结构变更、回归材料和实际验证等级 |
| 并行组织已定义的工作 | [项目与队列编排](../playbooks/program.md)；环境已安装时可选 swarm | 隔离执行与可复核产物；不负责认定分数提升 |

这些主流程和支持材料均在 agi-mode 内，单独安装即可使用。autoresearch、arena、reflect 保留为依赖 agi-mode 的兼容入口，不复制流程；swarm 等其他技能仅在已安装且确有需要时选用。只加载当前阶段需要的文件，各阶段共用一份协议和搜索状态。

## 从教训到候选

每项教训只需回答：

1. **证据**：哪次自然任务出现什么可观察失误或反复人工纠正？指出原始材料，区分事实与推断。
2. **机制**：失败来自发现、路由、知识缺口、指令冲突、执行、工具还是判定器？已有规则存在却没执行时，先考虑位置、可见性和结构约束，别再叠同义规则。
3. **可证伪变化**：改哪个最小表面，预期什么行为改变，怎样的结果会推翻它？
4. **边界**：哪些相邻合法请求不该改变？该教训只适用于本项目还是有更广依据？
5. **权威位置**：类型／schema／测试／脚本能可靠约束时优先使用；依赖判断的行为保留 skill 指导。复用既有位置，只有独立触发需求和重复用例都成立才新建 skill。

输出可以是一条实验记录，无需再造学习数据库。复盘的 Accepted 意味着值得实施或试验，不能称为已证明有效。

## 双层闭环

**内层改候选**：在固定协议下提出机制假设、修改、比较、保留或撤回。Arena 的多个方案与后续移植都算候选；Hillclimb 持有唯一搜索状态。

**外层修评测**：平台期先判断是能力不足还是尺子有缺陷。只能依据任务契约和原始材料纠正样本／判定器，并升协议版本、重跑基线。不能在同一轮同时改候选和尺子，再把分数变化归因给候选。

反例和回归案例一旦参与修订，就属于开发材料；可加入长期回归集，但不得再称未见确认集。持久规则应通过原失败重放、合法相邻场景与未参与改动的任务检查。缺少真实执行能力时可以交付修订，但标为未验证假设。

## 沉淀、观察与退役

保留最小学习记录：机制、采用的修改／版本、证据与协议、适用范围、反例、回退点和失效条件。授权允许的已知错误修正可以直接做，不要求每次经过长循环；只有行为对照支持时才宣称能力提升。

在后续已授权任务中核对该规则是否仍适用。模型、工具、分布或约束变化后，按受影响范围重新评测；旧机制已覆盖时删除重复指导，造成回归时撤回或缩小适用范围。观察不意味着擅自部署后台采集、定时任务或访问其他会话。

## 参考与本仓扩展

参考 [Automating eval design and hillclimbing with Claude](https://claude.dev/blog/automating-eval-design-and-hillclimbing/) 的代表性任务、判定器校准、测量噪声、过拟合防护和平台期诊断思路。

本仓在此基础上采用独立最终确认、同源分组划分、保质优化的事前损失界限、协议换版重测和安全恢复约定；这些是本仓的工程选择，不声称是文章原有的完整方案。模型、effort 和运行工具取当前环境可用配置，不复制文章示例的模型或价格。
