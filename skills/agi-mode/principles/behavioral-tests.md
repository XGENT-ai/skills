# 用行为契约检验实现

**触发**：新增、修订或评估测试，以及判断现有测试是否能捕获目标缺陷。

## 决策

通过消费者可用的接口驱动被测对象，检查具体输出、状态变化或协议效果。预期来自独立契约或已知样本，不通过同一被测实现计算答案。

检查测试在目标行为损坏时是否会失败。必要时用受控错误实现、正反样本或边界输入验证敏感性。测试允许代码更换内部结构，只要约定行为保持。

## 判据

能指出测试会捕获哪种真实回归。修 bug 的检查在未修复版本失败、修复后通过；合法与非法输入的区别来自实际被测路径。

## 边界与反例

空结果、禁止副作用、调用顺序、类型错误和关系不变量本身可能就是契约，不能因断言形式简单就删掉。mock 适用于隔离外部依赖，但要检查有意义的交互内容，并理解它未覆盖真实集成。

例如：测试拒绝请求时确实没有发出付款，还应有合法请求能付款的对照；只断言 mock 被调用不能证明金额正确。
