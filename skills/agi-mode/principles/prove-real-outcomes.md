# 在真实产物上证明结果

**触发**：准备接受实现、判断任务完成或把子任务结果交给下一阶段。

## 决策

每项结论使用能直接支撑它的观察。构建证明可构建，单元测试证明覆盖的局部行为，真实入口证明实际接线，远端读回证明动作后的状态。选与结论匹配的证据，不把更容易取得的信号升级为更强证明。

审阅实际差异与产物；自报成功、文件时间、旧截图、汇总数字只能提供线索。重复或关键检查值得脚本化时，保留可重跑的操作与输出。

## 判据

结论能追溯到本次入口、版本、输入和观察。失败、未执行、未知结果分别标记；验证方法的局限与结论放在一起。

## 边界与反例

证明强度与风险匹配，文案更正直接查看即可。环境无法提供真实入口时可完成局部验证，但不能把模拟结果称作生产验证。

例如：PR 已创建并不证明已合并；合并记录也不证明对应版本已部署并健康。

执行见 [评审与处置](../playbooks/review.md) 和 [合并与发布](../playbooks/shipping.md)。
