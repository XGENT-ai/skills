# 把上下文作为可恢复的工作状态

**触发**：大量输出、重复读取、长期任务、上下文压缩或交接。

## 决策

将原始大文件留在可定位的位置，用查询缩小到当前决定需要的材料。工作上下文保留目标、约束、关键事实、证据位置和下一步，而非每次操作的完整记录。

区分观察、推断与未知，保留足以回到来源的标识和适用版本。按需读取原则与流程，阶段结束更新已有进度记录。允许委派时可隔离大材料处理，但返回摘要仍应带出处与局限。

## 判据

新的执行者无需完整聊天就能确定当前状态和下一动作。关键结论可以回到原文或运行结果；截断输出中未读部分仍视为未知。

## 边界与反例

摘要不能替代决定成败的原始证据。为省上下文省掉版本、失败原因或用户约束，会增加重新工作成本。小任务无需持久账目。

例如：保存失败 trace 的路径、相关时间窗与已排除解释，而不是复制全部 trace 或只写“已定位”。

执行见 [会话交接](../playbooks/session-handoff.md) 与 [持续执行与恢复](../references/continuity.md)。
