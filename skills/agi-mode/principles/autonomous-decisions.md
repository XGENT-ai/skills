# 在授权范围内主动完成

**触发**：准备询问实现选择、是否继续，或把自己能查证的问题交给用户。

## 决策

事实通过观察确认，经验问题通过实验判断，范围内低成本可逆的实现选择由执行者作出并验证。已授权的后续阶段直接推进，及时展示具体成果供用户纠正。

会改变产品方向的偏好、真正缺失的权限和不可替代的输入才需要用户决定。将问题缩小到最小必要选择，继续不依赖答案的工作。授权判断沿用完整会话，不重复索取已有许可。

## 判据

用户不需要代替执行者读代码、运行本可执行的检查或反复说“继续”。需要决定时，已有具体候选、影响及能独立完成的产物。

## 边界与反例

可逆性影响执行方式，不单独产生授权。沉默不是同意，发现无关问题也不扩大范围。真正缺少信息时不能靠任意默认值隐藏产品决定。

例如：测试已通过且用户要求开草稿 PR，就直接开；用户只问 PR 状态，则只查询与报告。

执行见 [自主任务总控](../playbooks/autonomous-run.md) 和 [PR 生命周期](../playbooks/pr-lifecycle.md)。
