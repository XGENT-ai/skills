## 维护约定

- 改变本目录内容的执行者负责维护：先保存状态文件，再更新本索引；创建子目录时同时创建其索引。父索引仅在入口增删、移动或说明变化时更新，无变化不重写或刷新时间。
- 索引只作导航；状态内容更新不必改索引。归档须有依据并保留入口，移动保持对象 ID；缺失目标先标待核对，不因当前机器缺文件删除记录或历史。索引维护不授权搬迁、删除原文。
- 合并时按 ID 与路径核对本地实际文件，保留双方新增项及未解决冲突，不按时间覆盖；修补漏项、重复和断链，保留人工说明。查询只报告问题，维护模式才修复。
- 新增归档/分片目录同样有 index.md；大索引用 index-<分片名>.md 分片，首页列全范围，每项恰属一个分片。index.md 与 index-*.md 不作为事件读取或计数。
