## Brand Personality

本 App 的个性表现在**身份色、领域语汇、信息结构**上，**不**表现在另起一套控件、圆角和排版——那些跟门户同族（见 `DESIGN.md`）。

底座已定的调性（继承，不覆盖）：precise, engineered, quietly confident——开发者平台那一族（Linear / Stripe / Vercel 的手感），冷调中性色、几何无衬线（Space Grotesk）、机器值用等宽（JetBrains Mono）。界面应该像可信的基础设施：安静、该密的地方密、不为装饰而装饰。

## Anti-references

继承门户的四条：

- **过时的后台模板**（Bootstrap / AdminLTE / 默认 Ant Design Pro）：灰、通用、把每个功能都摆出来、没有观点。
- **无生气的老企业软件**（SAP / Oracle / 旧政务门户）：沉重、表单密度高而没有层级。
- **过度装饰的消费风**：到处渐变、吉祥物、什么都圆、游戏化。
- **AI 味**：奶油色背景、渐变文字、每个段落上面一条 eyebrow、一模一样的卡片网格。

再加两条**出仓 App 专属**（这两条是外部团队最常犯的）：

- **「iframe 里的第二个门户」**：App 内自绘版头 / 侧栏 / 租户切换 / 用户菜单 / 主题切换按钮 / 通知铃铛。同屏说两次，而且租户改过 App 名之后两处会说得不一样。
- **「移植过来的独立站」**：把一个原本独立的 SaaS 整个塞进 iframe，带着自己的登录页、自己的用户管理、自己的设置中心和自己的一整套设计语言。

## Accessibility & Inclusion

双主题（light / dark，由宿主经 `sdk.onTheme` 推送，App 自己落到根节点的 `data-theme`）都要过 **WCAG 2.1 AA**：

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1，**placeholder 也算正文**。
- 每个可交互元素都能键盘到达并有可见焦点态。
- 每个动效都有 `prefers-reduced-motion` 替代路径。
- 主 locale 是 `zh-CN`，排版要处理好 CJK（行高、标点、断行）；界面语言跟随宿主，不在 App 内自建语言切换。
- 状态色（成功 / 警告 / 危险）必须同时带图标或文字，不能只靠色相。
