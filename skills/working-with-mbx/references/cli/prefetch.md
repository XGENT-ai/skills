`mbx prefetch` [​](#mbx-prefetch)

- **Usage:** `mbx prefetch <CARGO_ARGS>…`

Download predicted remote artifacts without running Cargo.

## Arguments [​](#arguments)

- **`<CARGO_ARGS>…`** — Cargo subcommand and arguments whose previous manifest should be warmed.
