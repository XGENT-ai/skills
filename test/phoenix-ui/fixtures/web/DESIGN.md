# Fixture design

This is an Operate surface. Preserve system typography, semantic task table, visible keyboard focus and readable light/dark themes. Body text is 16px; page title is 28px. Desktop uses a 1100px content area. At 600px and below, hide Owner while preserving Task and Status. The filter dialog must close with Done or Escape and return focus to Filter.

Loading, default, empty and error states must remain distinguishable. No external fonts, imagery or network assets are required.
