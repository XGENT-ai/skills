elintp 用四种固定模板生成单文件离线页面，读者可以切换亮暗并按大纲阅读。

## gain | 四种模板共用一套阅读组件
:::conclusion 内容与排版分开
模型只写内容稿，脚本提供固定外观。
:::

:::reminder 分期不代表整条需求终验
P1 交付后，跨期需求仍停在可测试阶段。
:::

2. 按内容稿格式组织正文。
3. 生成页面后实际查看。
