## 2. 全部未关闭差距

### UI-01：打印永久丢失嵌入阅读器内容

- **位置**：U1，`U1-print-4.png`、`U1-print-light-a2-4.png` 的嵌入阅读器。
- **现状 → 期望**：图的最右侧节点被边界切断；第一张说明卡完整，第二张只显示开头，第三、第四张缺失。屏幕的两张 `reader-bottom` 图可见这些后续内容。打印应包含完整图、图例和全部说明，不能依靠打印后无法执行的内部滚动。
- **目标依据**：C7“打印含全部正文、表格、图和释义”；U1-1“图、标签、图例完整”。
- **具体修法**：**重做嵌入阅读器的打印呈现结构**。打印时提供进入宿主分页流的静态图和完整说明卡；图完整适配打印宽度，说明卡正常分页，取消打印呈现中的固定高度与滚动裁剪。仅隐藏工具条不能解决丢失内容。
- **验收**：light、dark 两种系统条件逐页核对右侧节点、全部图例、四张说明卡及各卡最后一行。
- **严重度／可挽回分**：**P0，2 分**：布局 1、交互与状态 1。

### UI-02：暗色系统打印仍保留深色宿主

- **位置**：U1，`U1-print-1.png` 至 `U1-print-4.png` 的页面背景、正文、结论块、指标及表格。
- **现状 → 期望**：系统 dark 条件下仍为深底浅字；系统 light 条件则为亮色。打印应固定使用亮色。
- **目标依据**：C7“固定亮色”。
- **具体修法**：在共用打印样式中覆盖打印颜色变量以及根节点、正文和组件的背景、文字、边框颜色，使打印样式同时覆盖系统暗色与手选主题；结论、提醒、指标、表格同步使用打印亮色变量。
- **验收**：系统 dark 且未手选主题时重新打印，宿主及组件均为亮色；确认 light 条件结果一致。
- **严重度／可挽回分**：**P1，1 分**，全部归视觉。

### UI-04：窄屏真实截图被缩成无法阅读的缩略图

- **位置**：U1，`U1-image-360-dark-a2.png` 中“已有流程图的真实截图”，约 y=296–497；尤其节点文字、图例和底部四张说明卡。
- **现状 → 期望**：整张桌面截图被压进约 320px 宽区域，轮廓完整，但其文字明显小于周围正文，说明卡内容无法可靠辨读。目标要求真实图片完整可读，窄屏宽内容可以在自身区域滚动。
- **目标依据**：U1 比较口径“已有真实图与截图须完整可读”；C5“宽表及宽图在自身区域滚动”。
- **具体修法**：修改**真实截图图片组件及其外层容器**：保留足以辨读原图文字的显示宽度，用限制在正文宽度内的独立横向滚动容器承载；取消将宽截图强制缩至容器宽度的呈现方式。保留现有素材与图注，无需重画图。
- **验收**：360px 视口下能在图片区域内查看全部宽度，节点、图例和说明卡文字可辨认，宿主页面不产生水平滚动；无脚本时仍能阅读图片。
- **严重度／可挽回分**：**P1，0.5 分**，归视觉中的图片可读性。未再按同一缩放问题重复扣布局分。

### UI-03：桌面大纲的当前项与实际阅读位置不一致

- **单元与位置**：U3；`U3-outline-second-1440-light-02.png` 左侧大纲与右侧第二节。
- **维度／严重度**：交互与状态；**P2 一般**。
- **现状 → 期望**：键盘激活第二项后，地址为 `#s2`，右侧第二节位于视口顶部附近，但左侧以背景及粗体标记第四项“接收方下一步回覆交付日期”。期望标记第二项“接收方同意介面，尚未承諾日期”，随实际阅读位置再更新。**依据：C4“滚动时当前项”以及链接跳到对应小节；更新后的实际操作记录亦确认该错配。**
- **具体修法**：修正**共用大纲组件的当前小节判定**：依据小节与固定阅读参考线的位置关系选出一个当前项，避免仅因后面多节同时进入桌面视口就由最后一项覆盖。保留当前背景、粗体等非纯颜色区分。修复后同时核对桌面 U3 的第二项跳转和滚至末节，避免用“点击后永远锁定当前项”掩盖滚动状态。
- **验收**：第二节靠近视口顶部时第二项为当前；滚至后续小节后当前项相应更新；窄屏已有正确行为保持。
- **可挽回分**：**1 分**。

### UI-05：无脚本阅读器仍显示主题按钮

- **位置**：U1，`U1-nojs-reader-1440-light-a2.png`，嵌入阅读器右上角带月亮图标的“深色”按钮，约 x=934–1009、y=112–156。
- **现状 → 期望**：无脚本条件下宿主主题按钮已隐藏，但嵌入阅读器的主题按钮仍清楚可见。无脚本阅读状态应隐藏主题按钮。
- **目标依据**：C7“无脚本时……主题按钮隐藏”。C3 允许嵌入主题独立，不豁免无脚本隐藏要求。
- **具体修法**：调整**嵌入文档的主题控件初始化方式**：默认隐藏主题按钮，仅在其脚本成功初始化后显示；无脚本保留图和说明的静态阅读呈现。无需改动宿主主题联动规则。
- **验收**：禁用脚本新开页面，宿主和嵌入阅读器的主题按钮均不出现，图、图例和全部说明仍可阅读；启用脚本后独立主题切换保持可用。
- **严重度／可挽回分**：**P2，0.5 分**，归交互与状态。其余风格、演示、导出按钮的具体无脚本行为未操作，不据此追加扣分。

## 3. 建议

- 窄屏工具条虽能操作，但当前需要横滚才能看到右端控件。可以考虑在窄屏换行或分组，使缩放更易发现；目标未要求所有控件同时可见，因此仅为建议，不扣分。
- 不因单次指针拖动没有位移就判定阅读器平移整体失败；已有图内横向滚轮成功证据。若后续要支持明确的触屏拖动体验，应另以实际触屏操作验收。
