# R1 · 实际操作记录

- 来源：当前源码公开 render.mjs 输出的本地文件；Chrome 157.0.8103.39，Playwright 1.59.1；2026-11-11；新上下文、DPR 1。
- 本文只记录实际执行的动作与观察；没有历史交互复用。

## U1–U4 · 各 1440×900 / 360×800 × light/dark

1. 打开各页，主题分别显示亮色、暗色。
2. Tab 到跳到正文，再 Tab 到亮暗按钮，Enter 切换；刷新后仍是刚选的主题。
3. U1/U2/U3 用键盘 Enter 激活第二条大纲，地址锚点变为 #s2。U1/U2 与窄屏 U3 对应项标为当前；桌面 U3 此时第二节顶端在视口 y≈110，当前标记为最后一节 #s4。滚到最后一节后当前项为该节。U4 没有大纲。
4. 表格区按 Right 后，U1/U2/U3 的 360 宽表在区域内向右移动约 40px，页面位置不横移。U4 的两列表无需横滚。
5. 从表格区 Tab 到表头释义，Enter 展开；按钮显示展开状态，释义列表出现在表下。

## U1 · 独立键盘顺序与焦点

360×800 新开后连续八次 Tab：跳到正文 → 切换亮暗 → 三条大纲链接 → 表格滚动区 → 表头释义 → iframe。前七个宿主控件都有可见的 3px 焦点轮廓。跳到正文见 U1-skip-focus-360-light-01.png；主题与释义焦点见对应桌面暗色关键帧。

## U1 · 嵌入阅读器

- 1440 与 360：点击阅读器放大，从 100% 变为 125%；点击自己的主题按钮，阅读器变为深色，宿主仍是亮色。
- 1440：在图内拖动 45px/25px，图相应平移；按重置回到 100%。
- 360：同一次指针拖动没有改变图的位置；重置可回到 100%。随后在图内实际横向滚轮 320px，图滚动到右侧，见 U1-reader-scroll-360-light-06.png；宿主保持原位。
- 在 iframe 文档内向下滚到底部，四张说明卡的后半部分进入可见区，见 reader-bottom 关键帧。默认帧与底部帧记录的是同一嵌入页的不同滚动状态。

## U2 · 三进度；U3/U4 · 语言

- U2 partial 页头显示“计划记录：做了一半”，正文依次为 built/verify/build/route/gaps/records。
- U2 todo 页头“计划记录：未完成”，两个小节 build/route，无大纲。
- U2 done 页头“计划记录：已完成”，三个小节 built/verify/gaps，有大纲。
- U3 控件为“切換亮暗”“大綱”“表頭釋義”“出處”，四个小节按请求、答复、约定、未决排列。组件中的示例正文由输入指定，界面语言与正文示例分开判断。
- U4 为英文控件；U4-ja 界面也是英文，html lang 保留 ja；不存在的图片显示 Image missing、missing-example.png 及图注；两段标签示例按文字显示，操作过程中没有弹窗。

## U1 · 无脚本与存储限制

- javaScriptEnabled=false 新开：主题与释义按钮不出现，释义列表直接可见；正文、截图、图仍在，详见 nojs 全页图。
- 浏览器 localStorage 被拒绝的新上下文：初次按系统暗色显示；键盘 Tab Tab Enter 后变为亮色，内容仍可阅读。此状态没有额外视觉差异，复用已有亮暗画面。

## U1 · 打印来源

- 系统 dark、尚未手动选主题：Chrome 生成四页 PDF；print-1 至 print-4 是该 PDF 逐页直接栅格化的画面。
- 系统 light：另开上下文补充生成四页 PDF；print-light-a2-1 至 print-light-a2-4 是补采 PDF 的直接栅格化画面。两次均未修订界面或内容。
