## 2. 全部未关闭差距

**UI-03 · 同一正文位置的当前项仍受操作路径影响**

- **单元、位置**：U3；R3 `U3-outline-second-1440-light-02.png`、`U3-outline-scroll-1440-light-03.png` 与 `U3-outline-last-1440-light-04.png`，左侧大纲及右侧第二节。
- **维度、严重度**：交互与状态；**P2 一般**。
- **现状 → 期望**：第二节点击后和实际回滚后，第二项现在都正确高亮，旧复现路径已解决。但点击末项时，正文仍保持相同位置，第二节靠近顶部，当前项切成第四项；上滚再滚回该位置又变为第二项。期望相同阅读位置使用一致的当前项判定。
- **证据**：操作 27、30 中，末项点击与回滚的 `scrollY` 均为 1449、各节位置相同，而 `current` 从 `#s4` 变为 `#s2`；操作 33、36 在 360 视口也记录了同类差异。窄屏图片中大纲已离开视口，状态事实依据操作记录。
- **目标依据**：C4 的滚动当前项要求；R2 UI-03 明确要求点击与滚动使用同一阅读参考线及候选规则。此处沿用该口径，未新增视觉标准。
- **具体修法**：继续统一**共用大纲组件的当前项状态**。锚点激活后也依据实际正文位置计算当前项，避免仅因点击目标或 URL 哈希而覆盖当前位置；保留已有粗体和背景标记。
- **验收**：保留已通过的第二项点击→上滚→回滚验证；补验末项点击→上滚→回到相同位置，两次当前位置反馈应一致。
- **可挽回分：0.5 分**，全部归 U3 交互与状态。旧问题已明显收敛，因此由上轮 1 分降为 0.5 分。

**UI-05 · 无脚本嵌入阅读器仍显示主题按钮**

- **单元、位置**：U1；R3 `U1-nojs-reader-1440-light-01.png`，阅读器右上角约 x=934–1009、y=112–156 的“深色”按钮。
- **维度、严重度**：交互与状态；**P2 一般**。
- **现状 → 期望**：宿主主题按钮已隐藏，嵌入阅读器的主题按钮仍可见；无脚本阅读状态下两者均应隐藏。
- **目标依据**：C7 要求无脚本时主题按钮隐藏；C3 的嵌入主题独立不构成无脚本例外。操作 39 与新图一致。
- **具体修法**：在**生成的嵌入文档**中默认隐藏主题按钮，仅在脚本初始化成功后显示；保留图、图例和说明的静态阅读内容。
- **验收**：禁用脚本重新打开时两个主题按钮均不出现；启用脚本后嵌入阅读器仍可独立切换主题。其他工具按钮未纳入本条扣分。
- **可挽回分：0.5 分**，全部归 U1 交互与状态。
