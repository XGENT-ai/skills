## 交付

对比页外壳：并排/单个两种视图、桌面 1440×900 与手机 390×844 视口、适应/100%、键盘切换、选择面板（原生 `dialog`）、不可用与重试（每 5 秒复查）、已选择后停用全部控件、中英两套文案。页面只通过 `/status`、`/heartbeat`、`/answer` 与服务交互，不用本机存储。

## 偏差（正文已就地修订）

- 缩放封顶为 1（§6.1）：栏比视口宽时按原尺寸居中，不放大。
- 选择按钮的可访问名称带方案名（「选择：方案 B · 看板」「保持现状：现状」）；capture 用 `{"role":"button","name":"保持现状"}` 精确匹配不到，用 `{"text":"保持现状"}` 或 `[data-choose="<id>"]`。
- 每栏最小宽 400px；关掉套件给 `body::before` 的纸纹（它会垫在每个方案后面）；根字号保持 16px。
