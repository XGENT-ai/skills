## 交付

- `hooks/claude/context-goal-guard.js`：按 §5.1 顺序判定；PostToolBatch 输出 `additionalContext` 提醒；Stop 在 `stop_hook_active` 非 true 时 `decision:block`（附 `background_tasks` 的 id 与命令/描述，单项截断 200 字），为 true 时 `continue:false` + `stopReason`；空操作无 stdout、exit 0。
- `hooks/claude/settings.example.json`：PostToolBatch / Stop 两个 handler，command 与 §5.5 一致，timeout 5。
- 必要偏差（已就地修订 §5.6、§9）：会话记录缺失、路径非法或读权限错误时无法判定 goal，按 §8 在 Stop 上告警（PostToolBatch 静默）；stdin 不可解析时事件未知，静默空操作。Node 25 下 `node --test <目录>` 不可用，§9 命令改为文件路径。
- `background_tasks` 项形态取自 2.1.288 内置 schema：`{id, type, status, description, command?}`。
