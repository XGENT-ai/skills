## 新发现（已写入说明并就地修订计划 §4、§11）

1. 后台任务完成通知唤醒的回合被 guard 结束后，界面显示「Goal not yet met… continuing」、状态栏仍为「/goal active」，没有「Goal paused」提示；此后 6 分 47 秒（check-in 1 分钟）无自动回合。行为上未续跑，仅界面标签不同。
2. Claude Code 界面「NN% context used」按扣除输出预留的有效窗口计算：155,100 token 时显示 86%（≈ 155,100 / 180,000），guard 计 78%。
3. 运行中删除 `settings.local.json` 中的 handler 后，`/hooks` 数秒内不再列出它们（无需重启）。
4. agent 用 `kill %1` 停止 Claude Code 后台任务无效，任务仍运行到结束；guard 的 Stop 请求已正确列出该任务。
5. 首次走查用的任务只需首尾单词，Haiku 只读首尾几行，54.6% 就完成 goal（未越线）；改为「最长单词」后才可靠越线。这次运行同时证明未越线时 guard 不干扰 goal 正常达成。
6. 范围外：本仓库 `.claude/hooks/xgent-statusline.js` 读 `context_window.total_tokens`（不存在时回退 1M），在 200k 模型上「K available」读数错误；未改动。
