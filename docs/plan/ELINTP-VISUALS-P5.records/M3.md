## 实施范围

| 区域 | 文件 | 内容 |
| --- | --- | --- |
| 输入契约 | `skills/phoenix-diagram/schemas/annotation.schema.json` | 核对：`sentences` 至少一句、每句 `annotations` 至少一条；每条 `note` 或 `fix` 至少一个，写 `fix` 必须 `issue: true`；`span` 必填且非空、`occurrence` ≥ 1；`meta` 不含 `evidence`/`repository` |
| 最小示例 | `skills/phoenix-diagram/examples/minimal.annotation.json` | 核对：两句四条标注，一条 `issue` 带 `fix`，第二句带 `title`、`aside`、`footnote`；`schema_version: 1`、`quality_profile: showcase` |
| 类型登记 | `src/input.rs`、`src/schema.rs`、`src/layout/mod.rs`、`src/render.rs`、`src/check.rs` | `DiagramType::Annotation`（`ALL` 长度 13）、schema 注册表、三类分派 |
| 语义校验 | `src/input/semantics.rs` | 集合表 `("sentences", "relationships")`；`annotation_spans` 定位不相交出现、按 `occurrence` 选取、全图从 1 连续编号；`annotation/span-missing`（缺失与越界）与 `annotation/span-overlap`（部分重叠、包含、相同；报输入顺序靠后的一条并给出另一条下标与两个区间） |
| 场景与事实 | `src/scene.rs`、`src/layout/annotation.rs` | `DiagramFacts::Annotation { sentences }`；760 宽、左右 28、正文列宽 704；13/700 标题、11 右对齐旁注、15/26 原文、卡片间距 10、左缩进 16、内边距 10、句间 30；行原子按词切分、超宽单词按字符切分，标记编号紧跟词段最后一片；每句一个 `annotation-sentence` 容器，每条标注一个节点 |
| 渲染 | `src/render/annotation.rs` | 根属性 `data-annotation-ui`、`data-reader-min-text="7.5"`；逐行 `<text class="t-primary an-sentence">` + `<tspan>`（plain/span/marker），marker 后首个 tspan 回基线；卡片含编号、引述、改法、点评、问题标签与 `data-annotation-number` |
| 静态图 | `src/render/static_style.rs` | 支持清单加入 `white-space`；`.an-sentence { white-space: pre }` 在静态 SVG 中保留 |
| artifact 检查 | `src/check/annotation.rs` | 逐句重建原文逐字相同；span 文字与起点、唯一 marker 及 `!`、卡片编号/标签/来源路径/引述改法点评/问题标签、编号连续与卡片顺序；失败统一 `artifact/semantic-text` |
| 证据门 | `src/evidence.rs` | 逐词标注是编辑性文字，`collection` 返回 `None`，不接受 `sources`/`repository` |
| 识别词 | `src/cli.rs` | `Types` 行加 annotation；`guide` 识别词覆盖 annotation、逐词标注、逐词、批注、文案标注、措辞与英文说法 |
| 五语言 | `tools/phoenix-diagram/viewer/locales/{en,zh-CN,zh-TW,es,ko}.json` | `diagram.description.annotation`、`annotation.fix`、`annotation.issue`、`node.context.annotation.note`、`node.context.annotation.issue` |
