## 4. 建议（不扣分）

1. **卡片等高留白**：1440 下第 1 组「概况」「成立的规则」两张卡片被拉到和中间卡片一样高，底部空出约 200 px（`U1-default-1440-light-01.png`）。Reader 卡片本身也等高，目标没有约束这一点。如果想减少空白，可以给网格加 `align-items: start`。
2. **标题字号小于条目**：卡片标题看上去约 16 px 粗体，条目约 17 px。K4 只规定字重，没有规定字号。可以考虑标题不小于条目字号，靠字重区分层级。
3. **条目间距偏大**：单行条目之间约 38 px（第 1 组中间卡片），沿用了正文段落间距，卡片显得偏高。目标没有规定，可以考虑卡片内的 `li` 用更小的 `margin`。
4. **打印时小节眉标落单**：「为什么成立」「量级」「风险与提前」留在上一页底部，h2 标题却在下一页开头（`p1-a2` 到 `p4-a2`）。这是模板层的打印分页问题，不属于 U1 卡片规范。可以给眉标加 `break-after: avoid`，或把它和 h2 放进同一个不可断开的块。
5. **阻止滚动传到页面**：可以在图的横向滚动容器上加 `overscroll-behavior-x: contain`，避免滚到尽头后继续带动页面。这只是辅助，不能替代新-1 的根因修复。
