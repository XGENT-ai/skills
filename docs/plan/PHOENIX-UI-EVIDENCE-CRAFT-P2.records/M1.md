- 事实接口（§5.6）：`RenderedFont`、`FailedWebFont`、`HanFontRun`、`HanFontFacts`、`Dom::text_line_texts`、`Dom::han_font_facts`、`SnapshotDom::set_typography`、`FakeDom::set_text_line_texts` / `set_han_fonts`；另加 `GENERIC_FONT_FAMILIES`，探针与规则共用。

- 备注通道（§5.7）：`ScanOptions.notes`；`detect` 在发现输出之后把备注逐行写到 stderr（`note: …`，只合并逐字相同的行）；`capture` 的 `scan` 返回发现与备注，条目在非空时写 `findingsNotes`，终端输出 `NOTE <状态> <视口> <文件>: …`。
- 排版探针（§5.5）：`typography.rs` 的 `collect` 与纯函数 `assemble`；`Page::platform_fonts`；`scan_loaded_page` 仅在带规则包时调用。
- 页内包已按 C-4 重新生成；ENGINE.md「Rule packs」补让位钩子与探针两段。
- 偏差（已就地修订计划 §5.3、§5.5、§5.6）：
  - 行文字与字体 run 只取在元素自身行内排布的文本；嵌套的块级后代是另一段文字。否则子列表的短项会被报成上级列表项的末行孤字。
  - 失败面归属用三个探针取证（失败面所在字体族单独、声明前缀、不存在的字体族），不在页内实现浏览器的回退判断；前缀与兜底结果相同且前缀含通用族时无法区分，记未核实并出备注，不报发现。
