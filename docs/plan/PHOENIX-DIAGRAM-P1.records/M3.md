## 交付与必要适配

三类通过公开 layout dispatch。Sequence 保留参与者/消息顺序、旧 fixed/H54/9px、新默认 spread、有效 quality、notes 换行、activations、segments 及 bounded 避让。Dataflow 保留 stages/分类/文字、自动端口与显式零值 pins、路由和 label capacity 联合修复。Lifecycle 保留旧 bands/cols/尺寸/显式路线，新 v3 的主轨、等待/恢复、共享出口/frame/junction/label owner；原始事实没有被派生几何替换。

ICU4X 与固定 Node 即使使用同代 Unicode 数据，词典算法仍不同。初版实际出现 16 个 CJK、随后 10 个 SEA 词边界差异；现从固定 ICU 77 源移植 CJK 全候选成本/NFKC 与四类 SEA 三词前瞻算法，复用完整 baked 字典，不做语料特判。Unicode 16 Han/Mark/JS 空白属性由固定 Node 生成；grapheme 使用 ICU4X compiled data。Cargo 新依赖版本固定，provider 启用 sync、zerofrom 启用 alloc，所有运行时算法为 Rust，不调用系统 ICU、JS VM 或网络。
