## 交付

`prep-image` 支持静态 PNG/JPEG/WebP 与非递归目录输入，按显示宽度 2 倍和额外像素宽输出，先透明裁边、再居中裁比例、最后 Lanczos3 缩放；透明图采用预乘 alpha 缩放并输出无损 WebP，不透明图输出 JPEG。输出携带来源、ICC，应用 EXIF 方向，生成 URL 编码的 `srcset`/`sizes`。本批输出先与全部输入及彼此比对，冲突输入不写出；每张输入处理后复核 SHA-256。单文件损坏、动画或缺来源独立报错。

公开 `read_provenance`、`write_provenance`、`Carried`，复用现有 PNG tEXt/JPEG COM/旁注载体。公开 API 的超长 JPEG 来源走旁注并清除会抢先被读出的旧 COM 来源；原 `embed-prompt` verb 的超长来源仍报错。原 verb 的 oracle 不重录，留 V-8 检验。
