## 偏差（已就地修订计划正文）

- 每个状态页在独立浏览器上下文中打开（§5.3 第 2 步）：同一上下文会让前一状态的登录与本地存储带入下一状态，与“从重新打开的页面执行步骤”不符。
- 滚入视口、取盒、遮挡/禁用判断在页内定位脚本完成，`cdp.rs` 未加 `scroll_into_view`/`box_of`，改为 `call_with_nodes`（§5.10）。
- `url_scan_options` 增加 `home`、`rule_pack` 参数；`file_url_to_local_path`、`BrowserEngine::launch` 改为 `pub`（§2、§5.10）。
- 报告增加 `outDir`、`invalidFile`、`findingsError`、`allowedWrites`、步骤 `warnings`；`/favicon.ico` 探测不计失败请求，同一失败请求去重（§5.8）。
- `fill`/`type` 的 `env` 值在 `observed` 只写变量名，不写字符数。
