## 已查证的限制

旧 `quality-continuous-v1/calibrate.json` 只有两个等权来源组，`minimum_groups=5`、`confidence_level=0.95`、`minimum_effect=0.05`。本轮原用途就是校准/基线诊断，未预留优化器或确认调用。

`skills/agi-mode/scripts/evolution/compare.py:baseline_diagnostic` 同时要求来源组数和乐观收益下界足够，才允许搜索。等权时有界半径为 `sqrt(2 ln(40) / n)`；n=2 时为1.92064558。即使假设基线Q=0、候选能到1，乐观下界仍为-0.92064558，不能超过0.05。因此本轮不能解除后续搜索门，与A/A具体分数无关。原轮次后续发现合法新增测试被误扣10分，49登记执行全部捕获/导出/清理，整体invalid；这个差异不能当作生成噪声或可改进余量。
