## 实施期修复

1. `inlineSVG` 回调从 `onCards(cards)` 改为 `onData({cards, table})` 一次交回两者；figure 分支相应接收。
2. metadata 解析从单一 `data-phoenix-cards` 扩展为 `data-phoenix-cards` 或 `data-phoenix-table`，各至多一个；统一报错「静态图数据须为根下的 metadata[data-phoenix-cards] 或 metadata[data-phoenix-table]，各至多一个」。
3. 新增 `parseTable` 校验 columns/rows 结构（恰有两键、columns 非空字符串数组、rows 每行等长字符串数组），不符报「数据表结构不合约」。
4. figure-data HTML 渲染（`details > summary + .table-scroll > table`）。
5. `page.js` beforeprint 展开所有 `details.figure-data`。
6. metadata 开标签校验改为按种类分别判重（cards/table 各至多一个，两种可共存）。
7. `render.test.js` 3 处旧 metadata 报错断言从 `/卡片数据须为根下唯一/` 更新为 `/静态图数据须为根下/`。
