## 偏差与实施期修复

1. **V-1 guide 场景词修订**（@implementation_route）：§9 原文『对比三种写法的耗时』含 waterfall 提示词裸词「耗时」，而 chart 提示词（§5.9 原文 14 词）无一项是其子串，原场景命中 waterfall。已就地修订为『三种写法的数值对比』并验证单命中 chart；§5.9 提示词表未改。
2. **行带 node-body 不得带 `c-mask`**：`check.rs` 的框检查排除带 c-mask 类的矩形；初版行带写成 `class="c-mask ch-band"` 触发 `artifact/node-box boxes:0` 级联（计数与标签检查随之失败）。已改为真实底色隔行条纹（`.ch-band` lane-fill/45%、`.ch-band-alt` lane-fill/25%），浏览器探针 no-paint 判定通过。
3. **图例检查属性**：`data-legend-kind/label` 仅 interactive 渲染写出，内容检查改用始终存在的 `data-legend-semantic-kind` + 图例文本比对。
4. **sourced 徽标误报**：初版徽标检查拿 `"sourced"` 与 `None` 比较必然不等；已修为「illustrative ⇔ 存在徽标且属性一致，sourced ⇔ 无徽标」，并新增 `sourced_evidence_draws_no_badge_and_still_passes_the_artifact_check` 测试。
5. **tests/input.rs**：不支持类型清单移除 `"chart"`（现为合法图型，保留大小写与虚构名用例）。
6. **--sync-dist 的 THIRD-PARTY 漂移**：构建同步会改写 dist 根部三方许可文件（不在 §1.2 改动面）；每次构建后以 `git checkout --` + `git clean -f` 还原，git status 确认仅剩 bundle 变更。V-5 复跑时同样处理。
