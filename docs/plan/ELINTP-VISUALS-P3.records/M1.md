# M1 · 静态上下文、样式派生与字体策略

状态：进行中（自动门与命令级验收通过；实际看图项环境缺失，见文末）

## 实现

- `tools/phoenix-diagram/src/render/static_style.rs`（新增）：静态 CSS 派生与安全 SVG 转换。引号感知的 `svg` 元素识别（属性值中的字面 `svg` 不算图面规则）、Viewer/Figure 两种来源分别处理、Viewer 的 `:has()` 规则跳过而 Figure 保持硬错误、`flex` 等被动布局声明白名单、`@font-face` 仅接受内嵌字体块、system 策略全链路拒绝 JetBrains。
- `render.rs`：新增 `FontPolicy`（embedded/system）与 `render_static(scene, id_prefix, policy)`；ID 前缀经既有 `namespace_svg` 作用于全部 `id`/`href`/`url(#…)`，根 ID 为 `{前缀}-figure`；Reader 分支零改动。
- `cli.rs`：`static <type> CANDIDATE OUTPUT.svg [--font-policy embedded|system]`，非法值退出 2。
- `delivery/finalize.rs::static_figure`：阶段 validate → static → browser-check；非 `.svg` 输出以 `static/output-extension` 退出 2 且不写任何文件；前缀 `pd{候选 SHA-256 前 8 位}-{策略}`；summary 写 `NAME.static-summary.json`。
