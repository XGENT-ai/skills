## 实现

- `tools/phoenix-diagram/src/browser/static_figure.rs`（新增）+ `static-probe.js`：每个主题写宿主页 `NAME.static-host.html`（`data-theme`、body margin 24px、svg `max-width:100%; height:auto`），在 DESKTOP_VIEWPORTS[0] 测量；两条覆盖（light/dark），每覆盖四项沿用既有检查名：`rendered-dom` / `viewport-containment` / `offline-resources` / `theme-state`；双主题背景不同写回两条覆盖；截图 `NAME.static.1440x900.{light,dark}.png`；宿主页检查后删除并计入 `browser-cleanup`。
- `cdp.rs`：`inspect_static`（导航宿主页并执行 static-probe.js、导航校验）与 `screenshot_static`（等待 `document.fonts.ready` 与两帧后整页截图）。
- `offline-resources` 按策略断言：system 无字体资源、无 `@font-face` 且计算字体族恰为 `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`；embedded 的 `@font-face` 全为 data: WOFF2、无 `local()`、族名为 JetBrains Mono。
- 登记路径：`review-record OUTPUT.svg` 读取 `NAME.static-summary.json`，要求自动门已过、SVG 身份一致、记录截图与 summary 一一对应。
