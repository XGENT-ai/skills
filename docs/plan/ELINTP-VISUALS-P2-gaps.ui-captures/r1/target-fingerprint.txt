## 规范要点

- C1：沿用固定阅读模板；第一屏先出现主题结论，系统字体，亮暗两套且正文、表格、图片与控件可辨认，不加载外部字体或资源。没有已确认的像素目标或新增 token 数值，不能以被测 CSS 反定目标（PRD §2.4、WORK-F1、WORK-F3；P1 冻结目标 C1/C3）。
- C2：360 CSS px 与 1440×900 下均无页面级水平滚动；宽图在自身区域滚动，长引用可换行，文字与编辑器不裁剪、不遮挡正文（PRD WORK-N1/AC-1；原 P2 计划 §6「既有体验」）。
- C3：所有新增操作可只用键盘完成，焦点可见；标注类型、状态与错误使用符号或文字，不只靠颜色；状态反馈经 `aria-live`、错误经 `role=alert` 呈现（PRD WORK-N1/AC-2；原 P2 计划 §6）。
- C4：审阅工具条默认收起，只显示“标注内容”、禁用的提交入口及“先选择内容块并添加标注”；开启后才显示内容块控件。已有标注显示条数、提交和“清除全部”；无标注不能提交。提交中禁用编辑，成功显示“已提交给当前 Agent”，失败说明原因并保留待提交内容（PRD §2.4、WORK-F4/AC-2；原 P2 计划 §6）。
- C5：审阅页只允许当前本机会话所需连接；终稿不依赖 Agent、审阅服务或网络。禁用脚本与打印仍按既有阅读页规则显示正文且不显示审阅控件（PRD WORK-N2/AC-1、AC-5；原 P2 计划 §6）。
- U1-1：任一内容块均可选择“没看懂 / 疑问 / 建议”并附一句话；空图注的现有图片和缺失图片也分别出现“＋ 添加标注”，每块至多一条，可编辑、删除；按钮 `aria-label` 带引文（PRD WORK-F4/AC-1；P2 gaps 计划 §5.1、§6）。
- U1-2：普通块引文仍是可见文字折叠空白后的开头 80 个 Unicode 字符；空图注图片的引文是内容稿中的完整原引用，不折叠、trim 或截断，长路径与连续空格逐字保留（P2 gaps 计划 D2、§5.1）。
- U1-3：升级续接不改变既有块 ID。每小节先按旧规则给原有可登记块编号，再按文档顺序给新增空图注图片追加 ID；旧 `result.json --previous` 及同轮同 `pageKey` 浏览器草稿仍附着原块，新图片可独立标注（P2 gaps 计划 C-3、§3.1、§5.1）。
- U1-4：新增、编辑、删除和清空保存当前轮浏览器草稿；刷新后未提交标注仍在。主动提交后，结果包含页面标题、小节、块引文、类型和原话，页面明确显示成功；只有真实提交才算送达（PRD WORK-F4/AC-1、AC-2；原 P2 计划 §6）。
- U2-1：作者明确确认后交付单文件离线终稿；保留正文、图片、缺失图片原引用、出处与精确内容稿，不显示标注、提交入口、审阅连接或待审数据（PRD WORK-F4/AC-6、WORK-N2/AC-4；P2 gaps 计划 D1、§5.2）。
- U2-2：新终稿只内嵌 `elintp-draft`，不再内嵌第二份 `elintp-assets`；审阅页与 `result.json` 的资源快照不变。从不含原图的空工作目录可用当前审阅页生成终稿，终稿中已有截图仍完整，缺失图片仍如实提示（P2 gaps 计划 D1、§3、§5.2、V-2）。
- U2-3：只拿不含快照的新终稿作 `--assets-from` 时退出 1，提示改用当前审阅页或 `result.json`，不生成或覆盖输出；带快照的旧 P2 终稿仍可读取（P2 gaps 计划 D3、§5.2）。
- U2-4：终稿保留亮暗切换与大纲定位；再次打开保留主题选择，正文与图片在两种主题下可辨认。终稿体积回到同稿 P1 两参数渲染的同量级，不再约为两倍（PRD WORK-F3；P2 gaps 计划 WORK-N3/AC-2、V-2）。
