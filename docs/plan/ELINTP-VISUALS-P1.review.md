## 1. 确认问题

### [P2] F-01 · SVG 资源引用限制须覆盖 URL 型属性

- 定位：[计划 §5.4](ELINTP-VISUALS-P1.md#54-图片与图)，448–453 行；D9；WORK-N2/AC-1、M2。
- 问题：自绘 SVG 使用 `fill="url(https://example.org/paint.svg#g)"` 时，标签合法且没有外部 `href`、事件属性或 `style`，仍符合当前准入规则。内联后保留外部资源依赖，不能保证图完全内嵌、打开阅读零网络。这里确认的是设计契约漏项，不声称已复现脚本执行。
- 证据：[PRD WORK-N2](../PRD-ELINTP-VISUALS.md#work-n2-终稿离线审阅仅限本机内容不执行) AC-1（337 行）；[W3C SVG 2 Paint Servers §14.1](https://www.w3.org/TR/SVG2/pservers.html#Introduction) 定义 fill/stroke 的 URL 引用；[SVG 2 Linking §16.1](https://www.w3.org/TR/SVG2/linking.html#URLReference) 定义外部引用与资源获取（2026-11-11 核读）。本结论由规范与计划准入规则对照得出，未做浏览器复现。
- 修订：在已有 SVG 校验内限定资源引用只能指向本文件片段，覆盖 href 以及 fill、stroke、marker-*、clip-path 等 URL 型属性；外部引用按现有格式错误处理。无需新增 CSP、sandbox 或清洗框架。
- 复核：核对 §5.4 与 D9 的保证一致；实施期由现有 V-3 白名单与 V-2 零网络检查承担，不增加验收门。
- 置信度：高，规则漏项可直接定位；阻塞：否。
