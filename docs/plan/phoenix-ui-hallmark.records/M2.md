## 交付

- `tools/phoenix-ui/crates/rules/src/lib.rs`：`ROWS` 补齐 8 条（顺序 transition-all、focus-outline-removed、wrapped-control-label、control-height-mismatch、unlabeled-inline-svg、redrawn-window-chrome、emoji-icon、font-family-count），实现 `RulePack::check_element_dom` / `check_page_dom` 分派。
- `tools/phoenix-ui/crates/rules/src/dom.rs` ★：6 条规则
  - `wrapped-control-label`：button / role=button|tab|menuitem / nav 内链接；text 1–40 字；子树无 `br`；按 F-08 只看「自有文本且无带文本子元素」的叶子后代，直接用 `text_line_rects` 的已合并行（无 2px 二次聚类）。
  - `control-height-mismatch`：文本类 input/select 与父元素下直接子元素中的 button/提交类 input/role=button 配对；高度 20–80、同行（中心差 ≤ max(4, 0.25×较小高)、水平间距 ≤ 24px）；高度差 > 2px 报在字段上。
  - `unlabeled-inline-svg`：最外层 svg 且宽高 ≥ 16；跳过 aria-hidden/可见性/role=presentation|none/aria-label(ledby)/子 title/受控上下文祖先（a、button、label、summary、role=button|link、带 aria-label 祖先）。
  - `redrawn-window-chrome`：元素前 6 个元素子节点中连续 3 个圆点；6–16px、宽高差 ≤ 1、border-radius ≥ 45% 宽（百分比直接比较）、背景 alpha ≥ 0.5 且有彩度、色序红[340,360)∪[0,20]/琥珀[25,60]/绿[85,160]、中心差 ≤ 2、相邻水平间距 0–12；用 `parse_rgb_or_any` 读颜色（F-09，oklch 同样命中）。
  - `emoji-icon`（页面级）：`\p{Emoji_Presentation}` 打头的整串 emoji（F-15）、font-size ≥ 20px、下一个元素兄弟或「唯一元素子节点→父的下一个兄弟」为 h1–h6；全页 ≥ 2 个候选时逐候选报。
  - `font-family-count`（页面级）：可见、有非空白直接文本、祖先（含自身）不吃 code/pre/kbd/samp/textarea/input/select/svg；取计算 font-family 第一个族名去引号小写；跳过 icon/symbol/awesome；系统别名（system-ui、-apple-system、blinkmacsystemfont、ui-sans-serif/serif/monospace）归一族；CSS 通用族名不计入（F-16）；≥ 4 族报 1 条页面级发现，snippet 按首次出现顺序列 `族名 (tag)`。
- 页面 fixtures ★（自写）：`tools/phoenix-ui/tests/fixtures/xgent/{controls,svg,chrome,emoji-icons,fonts,clean}.html`。
- `tools/phoenix-ui/crates/cli/tests/xgent_rules.rs` ★：`URL_EXPECTATIONS` 单一期望表（6 fixture × 2 宽度，规则 ID 列表）+ `url_scan_matches_the_fixture_expectations`（file:// URL、`--viewport 375x812/1280x800`、无浏览器时按 `capture_snapshot.rs` 方式跳过）。
- `tools/phoenix-ui/crates/rules/tests/dom.rs` ★（18 个用例）：正例、plan 列出的反例与边界、oklch 圆点、零尺寸/无父节点不 panic。

## 偏差与说明

- V-4 的完整证据（固定 debug 二进制副本、逐 fixture×宽度命令与输出）按计划 §9.1 在 M5 收口记录；本里程碑记录的是同一期望表与同一测试在真实 Chrome 的首次通过，不冒充 M5 的最终证据。
- `wrapped-control-label` 的「叶子文本后代」与 `text_line_rects` 已合并行按评审 F-08 修订实现；`control-height-mismatch` 的「同行」判定按计划几何口径实现，未新增快照属性（C-7）。
- `redrawn-window-chrome` 只看元素前 6 个元素子节点（§5.3 原文）；`emoji-icon` 的页面级候选 ≥ 2 才报，与计划一致。
- 页面 fixture 的期望值只记录 xgent 规则 ID；内置规则在该 fixture 上的行为不纳入本表。
