- `src/evidence.rs`：`SourceEvidence`（none/verified/partial/unverified，repository、observation、references、unsourced）与 canonical 摘要；`verify(input, repo_root)` / `verify_with(..., &GitRunner)`；`bound(input, metadata)` 供严格当前性在不重跑 git 时核对 HTML 内证据。结构错误以 `repository/*` 停在 input 阶段：repository-required、revision-invalid、url-invalid（凭据时 evidence `reason: credentials`，消息经 redact）、provider-invalid、links-unsupported、path-invalid、path-escape、line-required、line-range-invalid。

- `src/evidence/git.rs`：参数数组、清除继承的 `GIT_*` 后设 `GIT_NO_LAZY_FETCH=1`、空 `GIT_ALLOW_PROTOCOL`、`GIT_TERMINAL_PROMPT=0`、`GIT_OPTIONAL_LOCKS=0`、`LC_ALL=C`，每条命令 `--no-replace-objects -C <root>`、独立进程组、30 秒超时杀整组。核对顺序与 12 个原因码按计划 §5.3；工作树逐段 lstat 不跟随链接。
- 接入：`validate`/`deliver`/`finalize` 增 `--repo-root DIR`（不存在即 `arguments/invalid`，exit 2），其他命令不接收；配置摘要加入 `evidenceSha256`（无来源为 null）；校验与交付回执的 `evidence` 增 status、evidenceSha256、repository、counts、unverified、unsourced，finalize 回执与 summary 增 status 与 evidenceSha256；HTML metadata 增 `sourceEvidence`；严格当前性核对 HTML 证据与回执摘要、引用与 candidate 一一对应，失配报 `provenance/evidence-mismatch`。
- Reader：`PhoenixDiagram.sourceEvidence` 读 `metadata.sourceEvidence`，提供 `state(id)`；节点 aria-label 追加已核对数量与「待核实」「未提供来源」；护照按三态显示（已核对 web 链接、仅本地、待核实附原因且无链接），语气用内联自定义属性复用已审计 CSS；查找沿用 `node()` 纳入全部来源路径；导出清理沿用原属性名。
