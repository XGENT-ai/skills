## 交付

- 输入：`DiagramType` 十变体与 `has_legacy_contract`；合同解析为 显式 → marker → 原五类 legacy-2.17 / 新五类 phoenix-v1，新五类遇 legacy 报 `input/contract-unsupported`。schema 注册表按 `(kind, contract)` 查找。五份新 schema 为参考原件加 marker，timeline 另加 D7 `precision`。延期字段：brand、`meta.views`、legacy `meta.animation` 改报 P3；`sources`、`/meta/repository` 不再延期。
- 语义门（`input/semantics.rs`）：erd 列重复、fk 目标表/列、自引用、网格占格与缺位置；class 成员重复、半列占格、realization/inheritance 种类、继承环；tree 重复、缺父、根数、环；timeline 时区、时间戳与日历、lane 重复与引用、事件重复、D7 日精度；waterfall 计时矛盾、缺 end/duration 非 incomplete、缺父、环。tree/timeline/waterfall 沿参考诊断码；erd/class 的实体与关系身份沿 P1 `input/duplicate-id`。
- `format/time.rs`：`parse_timestamp`（V8 边界）、`valid_calendar_date`、`zone`（命名区、ICU 额外别名、固定偏移）。`wall`/`offset_label` 与数字格式留 T-4。
- 场景（`scene.rs`）：五个 `DiagramFacts` 变体、`TimelineEvent`/`WaterfallSpan`、`Relation.marker_start/end`（`Marker`）、`Node.detail_rows`；新字段在空/缺省时不序列化，原五类场景字节不变。`delivery/metadata.rs` 绑定新事实（tree 边由 parent 派生为 `{from,to}`）。layout 对新五类暂返回 `layout/unsupported-type`，由 M2/M3 替换。
- i18n：装配器输出唯一规范化目录 `assets/catalogs.json`（`Archify`/`ARCHIFY` → Phoenix 身份，加 `viewer/catalog-adaptations.json` 的 18 个键：zh-TW/es/ko 补 `downloadPngInstead`，五语言新增日精度两键、来源三态三键、12 个原因码），模板嵌入同一对象；`--check` 断言五目录键集合、占位符一致、无 Archify 残留且适配不得覆盖既有消息。`src/i18n.rs` 读同一文件：覆盖 → 内置 → en，占位符不符的覆盖忽略，无 `meta.locale` 时覆盖不登记，未支持语言回退 en。
- 身份（D8）：crate 0.2.0、`VIEWER_REVISION` phoenix-v2、HELP/guide 十类；`build.rs` INPUTS 收窄为 `skills/phoenix-diagram/schemas`，JS 镜像同步；脚本、bootstrap、模板 generator 与测试常量同步。
