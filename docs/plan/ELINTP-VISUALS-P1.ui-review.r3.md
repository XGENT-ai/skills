## 差距清单

### UI-03 · [P2 · 停滞预警] 同一正文位置的当前项仍受操作路径影响（U3 · 交互与状态 · 可挽回 0.5）

- 位置：[点击第二项](ELINTP-VISUALS-P1.ui-captures/r3/U3-outline-second-1440-light-02.png)、[滚轮返回](ELINTP-VISUALS-P1.ui-captures/r3/U3-outline-scroll-1440-light-03.png)、[点击末项](ELINTP-VISUALS-P1.ui-captures/r3/U3-outline-last-1440-light-04.png) 的左侧大纲和右侧第二节。
- 现状 → 期望：点击第二项后及上滚再回滚均已正确标第二项。但点击末项时正文仍在相同位置而标第四项；离开再回到该位置又标第二项 → 相同阅读位置的当前项判定一致。
- 证据：[实际操作](ELINTP-VISUALS-P1.ui-captures/r3/observed-interactions.md) 27/30：末项点击和回滚均 scrollY=1449，第二节 top=109.5625，current 从 #s4 变 #s2；33/36 窄屏同类事实由操作记录覆盖，窄屏该屏看不到大纲。
- 依据：C4 滚动当前项要求；R2 UI-03 的同一阅读参考线、同一候选规则。沿用编号依据为同一 U3、同一阅读位置反馈依赖操作路径、同一期望；原第二项子路径已解决，剩余末项子路径，扣分由 1 降为 0.5。
- 修法：统一共用大纲当前项状态，锚点激活后依据实际正文位置计算，避免仅用点击目标或哈希覆盖当前位置；保留粗体及背景标记。先诊断冻结口径与页尾跳转意图，争议提交用户确认，不擅改期望。
- 验证：第二项旧路径保持正确；末项点击→上滚→回到相同位置，当前位置反馈一致。
- 来源：独立评审 R3 A；部分解决；P2；可挽回 0.5，全部归 U3 交互与状态。
- 主 agent 核对说明：三张桌面新图确实在相同正文位置显示第二或第四项。计划 §6.2 及最近修复记录明确允许「刚经锚点跳转且仍在页尾」的临时当前项，离开页尾恢复位置判定；评审按冻结目标和上轮一致性口径继续扣分。此处记录实现取舍与评审的分歧，不改分、不删差距、不替用户修改目标；由后续修复方核实，必要时提交期望调整。

### UI-05 · [P2 · 待裁定] 无脚本嵌入阅读器仍显示主题按钮（U1 · 交互与状态 · 可挽回 0.5）
