## 原版失败分型与 M2 前置

以下都是已读源码、输出和固定输入支持的 M1 差异，不修改历史 oracle 来掩盖。V-1 的基线任务已完成；只有记录原版事实，不代表这些差异已在 Phoenix 关闭。

- **WASM 数值**：27 项全在 `shared.color/relativeLuminance`、`contrastRatio`，native 与原 golden 精确一致，WASM 浮点末位不同。foundation 的 math_pow 最终使用平台 powf；M2 定位最小共享数值实现并同向量验证，不全局放宽容差。
- **目录 oracle**：`detect-dir-json-all-fixtures` 从 436 到 437 findings，唯一新增为 italic-serif-display.html 的 `Inline Em Inside Roman`、Fraunces 72px；两边 exit 2，已有 findings 全保留。该单文件 golden 已包含此 finding；目录 golden 漏项待 M2 进一步交叉核实。上游 DELTAS 明写该历史段落不再 accepted，但 run.mjs 的全文件正则仍收了其 ID，故退出 0 不能当 860 exact pass。
- **原测试竞态**：首次并行工作区运行的 dev_url listener-drop 断言失败，串行整组通过；后续统一入口运行又见 agent_target 读取刚出现 server.json 得空字节/EOF，独立单用例通过。完整源码 baseline 的 819 pass 与这些失败分别保存；M2 修复有据测试/发布就绪竞态，不增加 skip。
- **生成工具**：Binaryen 111 把有效输入优化成无效模块（unknown type form）；117 修复有效性，Mac ARM64 archive SHA-256 已核对为 `f2d962ff294b38ea3cfbbae8f6c728089d9375a57bac9a1880eb86779d6d3a84`。需要 M2 将显式工具准备扩展至五平台、切掉 wasm-pack 版本查询。npm PATH 重排与继承 __MISE 状态已导致真实 wrapper 检查失败，统一清理和重新注入后校验实际工具；MISE_AUTO_INSTALL/EXEC_AUTO_INSTALL=false，先核实工具确已 installed/active，阻止同版本全局 fallback 冒充。
- **补丁与布局**：E12 IME/Windows 仅登记候选补丁及 before/after/source hash，未 apply。native PROVIDER_DIRS 与生成器的 19-provider 范围不同，Codex `.agents`/`.codex` 职责、Rust hook writer 都需 M2 对齐，不凭宣传当支持。
- **旧包来源**：0.3/0.4 的最初 Git 候选与实际安装器不同；迁移输入分别精确匹配 f1e2554/4724424，保留不匹配证据。四个旧包均只有一个主 skill、不支持旧计划假设的 auxiliary flag；五个附加 skill 明标固定 Git 来源的其他渠道安装。早期 pin、旧 JS body、Windows junction、个人加载优先级和真实 running live 仍需 V-4/V-5 独立证据。

M2 继续：稳定公开身份/状态根/JSON 契约，关闭 upstream 更新、目录、telemetry 和第二 agent CLI；固定本地库与单源渲染；重建 native/WASM/开发 tarball 与五平台 CI，并核对依赖公告/许可。M2 候选 diff/SHA/ref/CI 可审阅后再请求推送授权，未执行外发。
