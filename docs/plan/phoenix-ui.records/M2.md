## M4开发包的隔离使用

可用tarball：local/phoenix-ui/development-package-final/xgent-ai-skills-0.7.0-rc.0.tgz；本机release：local/phoenix-ui/development-release。其他机器先取得对应平台制品，不能用darwin-arm64代替；接受前核对上表tarball、VERSION/bundle/native摘要。

在新的临时consumer用Node18的npm执行 `install --offline --no-audit --fund=false <tarball绝对路径>`。建立独立项目，把 `PHOENIX_UI_HOME` 指向consumer自有engine-cache。用安装后的 `node_modules/@xgent-ai/skills/bin/phoenix-ui.js` 执行 `engine install --project <项目> --release-dir <制品目录> --json`。进入项目执行 `skills install --providers=claude,agents --scope=project --yes --no-hooks --bundle-root=<包内vendor/phoenix-ui/bundle绝对路径>`，随后 `skills check --bundle-root=<同目录> --json`；本轮已实际按此安装。--no-hooks仅安装skills/agents/commands，不要求hook设置文件。

此入口用于M4设计子集消费；五个辅助skill融合、默认npm接线、真实provider加载及迁移/回滚尚未实施，不在开发包证据范围。
