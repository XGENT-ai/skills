## 精确分数基础 / V-7局部

- Decimal直接读取JSON原numeric token或数字字符串，用u128系数和十进制scale计算；存储/序列化为规范十进制字符串，不经f64、epsilon、舍入或截断。范围0–10；单值数值token最多4096字节，规范化后最多36位小数，超限明确错误，不变成另一个分数。CLI输入错误映射仍待接线。
- 四维按3/3/3/1校验并求和；求和2.4+2.3+2.6+0.7恰为8。比较保留0.5确认边界与1.0增长边界的精确开区间；科学计数法、零与尾零规范化可恢复。这里只提供算术基础，未实现预备通过、独立确认、平台期窗口或验收判定。
- 嵌套judge字段也保留原数值token；0.700000000000000000000000000000000001参与四维求和得到8.000000000000000000000000000000000001。非法、非有限、越界与过长输入拒绝，不限制为0.01步长。
