## 未关闭差距

### UI-01 · U4 · 视觉 · P1 · 可挽回 1.0（原 新-1）

- 位置：U4-default-1440-light/dark.png 画布 12 点方向左侧收尾扇区（Fixtures）及右侧列表第 6 行色块；U4-static-1440-light/dark.png 同位置；U4-table 截图列表与节点索引「Fixtures」chip 同色。
- 现状 → 期望：收尾扇区与列表色块为中灰/石板灰（亮暗两主题相同）→ 目标包 S2：「饼图收尾扇区（第 6 块）与列表色块用绿系强调色，列表色块与扇区同色」（G-02 强调色槽）。现为中性灰，指定的强调槽未按规范实现。
- 修法：改引擎饼图配色槽——把收尾扇区专用强调槽从灰中性 token 换为绿系强调 token（亮暗各配一档，与系列普通绿区分开），列表色块与节点索引 chip 引用同一 token 以保持「色块与扇区同色」。纯配色 token 替换，不需要动布局或重做素材。
- 说明：这是本轮命名验收点中唯一未达成的部分；图面其余部分（同色性、占比、自明性）达标。

### UI-02 · U1＋U2 · 视觉 · P2 · 可挽回 U1 1.0 ＋ U2 1.0（原 新-3）

- 位置：U1/U2 的 default 与 table 四张阅读器截图左下 Legend/图例区，「键 · 名称」中的名称文字（"Before""After""p50""p95"），亮暗主题一致出现。
- 现状 → 期望：系列名称文字上贯穿一条横线，形似删除线（U3 图例名称「当前值/上限/仅上限/超限」无此线，同产品内样式不一致）→ 图例名称应为可读常规文本（S1「键 · 名称」；S7 文字图例应帮助自明——删除线惯常读作「已删除/已停用」，误导系列状态）。
- 修法：在阅读器图例组件的系列名样式里去掉贯穿横线（排查该文本元素上的 `text-decoration: line-through` 或等高伪元素/边框装饰），与 U3 图例名称样式统一；亮暗主题各复核一次。同时核对静态 SVG 图例是否共用该绘制（评审在整页截图分辨率下不可分辨）。

### UI-03 · U2 · 布局 · P2 · 可挽回 1.0（原 新-2）

- 位置：U2-default/U2-table-1440-light/dark.png「低负载」数据点处；U2-static 两主题同（缺陷同源，S6 一致）。
- 现状 → 期望：A（0.1）与 B（0.3）两点几乎重合，标注「A 0.1」「B 0.3」上下行距≈0，标记圆圈压住「0.1」「0.3」数字，x 轴线穿过「B 0.3」→ 数值标注应互不重叠、不压数据点标记与轴线（比较口径「没有溢出、遮挡、截断」；S7 图自明、S8 数值可读）。
- 修法：改折线图数值标注定位逻辑：同一 x 附近多系列点重叠时按系列序把标注分别放到点上方/下方错开（最小间距≈标注行高），y 近 0 的点统一抬到轴线上方，标注与圆点标记之间留 ≥2px 间隙。现有 SVG 文本元素内调整，不需要换组件。

### UI-04 · U3 · 视觉 · P2 · 可挽回 1.0（原 新-4）

- 位置：U3-default/U3-table-1440-light/dark.png「导出」行；U3-static 两主题同。
- 现状 → 期望：「仅上限」虚线框画满整个标尺（右缘到标尺末端，与另两行轨道右缘对齐），上限刻度线落在框内约 4/5 处、虚线继续延伸过刻度 → S4/D-02：「长度到上限」，即虚线框右缘应止于上限刻度。该行几何本身自洽（逐行标尺 = 1.25×max(当前值， 上限)，刻度=上限：检索 13→52%、刻度 80%；导入 25→80%、刻度 64%；导入红填充明确越过其刻度，超限可读），唯独框长超出。
- 修法：改限额图仅上限行绘制：虚线框宽度由「画到标尺末端」改为「止于上限值位置」（右缘与该行上限刻度线重合收口）；行标尺与刻度位置不动；虚线段样式与图例「仅上限」符号保持一致。

## 建议（不扣分）

- 建-1：阅读器底部节点索引摘要按固定宽度截断，把数字截成「After 26…」「p95 2…」（U1/U2 default 与 table 可见；U3 三节点无截断，说明是宽度分配问题）。S1–S8 未覆盖节点索引，无扣分依据；建议加宽摘要列、或数值超宽时换行/隐藏摘要段——被截断的数字没有含义。
- 建-2：四个单元画布利用率低——绘图区只占画布中部一小块（U1/U2 绘图区约 360×370px，四周大片点阵空白；U4 环图＋列表集中左侧）。无设计稿约束，属偏好：可放大绘图区/行带或收紧画布高度。
- 建-3：数据表数值列左对齐（U1–U4）；位数悬殊的数字（0.1 与 1234567）左对齐不便比大小，可改右对齐。规范未约束对齐。
- 建-4：U2 y 轴刻度显示原始数字（2500000 ms）；可加千分位分隔符提升可读性（不改变数值，不违反 S8「不舍入」）。规范未要求。

## 看不出的格子（评审原文）

1. U1/U2 static 四张截图：静态 SVG 图例名称是否也有贯穿横线——整页截图里 SVG 仅约 372px 宽、图例文字约 8px 高，1px 装饰线不可分辨；需放大裁剪图例区或查 SVG 内对应文本样式。
2. 全部单元：悬停、按下、焦点可见与键盘操作（图例项、details 折叠头、工具栏按钮、表行）——交互采集只覆盖展开与复制两步，无 hover/focus/键盘记录与截图；不推断通过或失败，本轮交互分只基于已验证的主路径与状态。
3. 工具栏主题开关、Classic/经典、Still/静态、Export/导出、全屏、缩放控件：不在本轮单元矩阵内，无证据，不评。
4. U3 填充/刻度的精确像素比例：提供分辨率下无法精确测量；「虚线框越过上限刻度」这一事实本身可见（刻度线两侧均有虚线段），但「约超出 25%」是按可见相对位置估算，精确比例待修时用引擎产物核实。
5. U4 列表色块与扇区是否逐像素同色：目视同色（灰=灰），无取色证据；改绿时需保证两者引用同一 token。

## 总评（评审原文）

- 最低分单元：**U2（8/10）**——近零数据点的数值标注相互压叠并压住标记与轴线（UI-03），叠加图例名称删除线样式的共享缺陷（UI-02）。
- 四个单元的页面结构、亮暗主题、表格规范（S3）、静态同源（S6）、图文一致（S8）、复制主路径全部达标，无 P0。
- 需要结构性改变的地方：**没有**。四处差距均为 token/样式/定位级修复：U4 换收尾扇区配色 token（非重做素材）；U1/U2 去图例名称贯穿线；U2 加标注避让逻辑；U3 虚线框收口到上限刻度。U3 的逐行标尺几何（1.25×max 归一）整体自洽，只需修框长一处。
