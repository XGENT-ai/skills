## 规范要点

- S1（图例键，G-01）：多系列柱状/折线图的图例色块内文字是系列键（A、B…），与右侧「键 · 名称」的键一致；色块内只有键、不写系列 id，不溢出色块、不与右侧文字重叠（计划 §5.1；PRD WORK-F6/AC-2「系列之间除颜色外还有文字或图形上的区分」）。
- S2（强调色槽，G-02）：限额图超限行的填充与「超限」图例色块用红系强调色，亮暗主题下都比正常系列填充更醒目；限额图正常填充刻意弱化（fill-opacity .55）以衬托超限（计划 §5.2、D3，用户 2026-11-15 选定弱化方案）。饼图收尾扇区（第 6 块）与列表色块用绿系强调色，列表色块与扇区同色（计划 §5.2）。
- S3（数据表纯数字，D-01）：柱/折线/饼图数值单元格只写数字（如 4200、0.1、1234567），不带单位、系列键或 %；单位只在列头；列头括号随语言（zh 全角「p50（ms）」、en 半角「Before (ms)」）；饼图占比单元格只写数字（如 20），占比列头 en「Share (%)」（计划 §5.3；D-01）。
- S4（仅上限行，D-02）：没有当前值的限额行画虚线框（无填充、暗色文字色描边、虚线段），长度到上限，与有当前值行的实心填充一眼可分；图例出现「仅上限」条目（zh-CN），符号为同样式虚线框；没有这类行时不出现（计划 §5.4；D-02）。
- S5（note 行，M2 修复）：带 note 的限额行，标签与备注在阅读器字号下不越出行带、不互相重叠（计划 §5.4）。
- S6（静态同源，WORK-F9/AC-5）：embedded 静态图的图例键、强调色、仅上限样式与阅读器一致；SVG 内 `data-phoenix-table` 与阅读器表格逐格相同——逐格相同由主 agent 机械比对，评审只看静态图图面与阅读器一致（计划 §5.5；PRD WORK-F9/AC-5）。
- S7（图自明，PRD §2.4 数值图表行）：图自带图例、单位与标记含义，可独立看懂；数据表可展开阅读；状态与系列的区分不只靠颜色（键字母、文字图例、超限标注）。
- S8（图文一致，WORK-F6/AC-1 本期图面部分）：图中每个标签、系列、数值与单位均与输入一致；数据表数值与图面标注一致（如 1234567 不被舍入）。
